# 文献慢读搭子

`paper-reading-companion` 是一个陪你逐小段精读学术论文的 Codex 技能，尤其适合英文理工科论文。

- 每轮围绕一小段正文、一组公式或一幅图推进，结合原文、中文翻译和解释。
- 核对符号、量纲、图注和适用条件，区分作者的实验结果、模型解释和推断。
- 记录停读位置，按需核对关键参考文献。

## 安装

在你的项目根目录运行：

```sh
git clone https://github.com/Fallen-faction/paper-reading-companion.git .agents/skills/paper-reading-companion
```

然后在 Codex 对话中提供论文 PDF、截图或原文，指定想读的位置。例如：

> 用 $paper-reading-companion 从摘要开始，陪我逐段读懂这篇论文。

技能入口见 [SKILL.md](SKILL.md)。
